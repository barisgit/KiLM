The `kilm update` command group updates KiLM itself. It detects how KiLM was installed and uses the matching upgrade mechanism.

:::caution[Breaking Change in v0.4.0]
The `kilm update` command behavior changed in KiLM v0.4.0:
- **Now:** Updates KiLM itself (self-update)
- **Previously:** Updated library content (now use `kilm sync`)
:::

## Usage

```bash
kilm update check [OPTIONS]
kilm update info [OPTIONS]
kilm update perform [OPTIONS]
```

Running `kilm update` without a subcommand prints the available subcommands.

The latest version found on PyPI is cached for a day in `~/.cache/kilm/version_check.json`; within that day `check`, `info`, `perform`, and the update notice shown before other commands reuse it unless a bypass option is given. `kilm --help` never runs the check, so help output does not depend on the network or on the cache being fresh.

## Subcommands

### check

Checks PyPI for a newer version without installing it. Exits with status `1` when an update is available or the latest version cannot be determined, and `0` otherwise, so it can be used in scripts. When PyPI cannot be reached or answers unusably, `check` reports that the latest version is unknown instead of claiming KiLM is up to date.

- `--force` / `--no-force`: Bypass the cached version check and query PyPI. Default: `--no-force`.
- `--quiet`, `-q`: Print output only when an update is available.

### info

Shows the current version, whether a newer one exists, the detected installation method, whether automatic updates are supported, and the manual update command.

- `--force-check` / `--no-force-check`: Bypass the cached version check and query PyPI. Default: `--no-force-check`.

### perform

Installs the update. If KiLM is already up to date, it exits without changes unless `--force` is given.

- `--target-version`, `-t` `TEXT`: Install this version instead of the latest release, even if it is older than the installed one. Without `--force`, asking for the installed version changes nothing. A value that is not a version number is rejected with status `2`.
- `--force`, `-f`: Reinstall even if KiLM is already up to date.
- `--dry-run`: Show the command that would run without changing anything. Like a real update, it exits with status `1` when the installation method does not support automatic updates.
- `--no-cache`: Bypass the cached version check and query PyPI.

Every subcommand also accepts `--help`.

## Supported Installation Methods

| Method | Automatic update | Update command |
|--------|------------------|----------------|
| **pipx** | Yes | `pipx upgrade kilm` |
| **pip** | Yes | `pip install --upgrade kilm` |
| **pip (venv)** | Yes | `pip install --upgrade kilm` |
| **uv** | Yes | `uv tool install kilm@latest` |
| **conda** | No | Not yet published |
| **homebrew** | No | Not yet published |
| **nix** | No | `nix flake update`, then rebuild the configuration or profile that installs kilm |
| **unknown** | No | Update KiLM with the tool that installed it |

KiLM reports **unknown** when nothing identifies the installer, for example a distribution package, rather than guessing pip.

With `--target-version`, the automatic methods install that exact version: `pipx install --force kilm==VERSION`, `uv tool install kilm==VERSION`, or `pip install --upgrade kilm==VERSION`.

For methods without automatic updates, `kilm update perform` prints the manual instruction and exits with status `1`. When the installer itself fails, it prints the last lines of the installer's error output and the command to run by hand, and exits with status `1`.

## Examples

**Check for updates:**

```bash
kilm update check
```

**Show installation details:**

```bash
kilm update info
```

**Update KiLM to the latest version:**

```bash
kilm update perform
```

**Preview the update, then reinstall the current version:**

```bash
kilm update perform --dry-run
kilm update perform --force
```

## Troubleshooting

**Update fails with permission errors:**
- For system pip: Try `pip install --user --upgrade kilm`
- For pipx: Reinstall with `pipx uninstall kilm && pipx install kilm`

**Cannot detect installation method:**
- Install via pipx for the best CLI tool experience: `pipx install kilm`

**Network/PyPI connection issues:**
- Check your internet connection
- Try again later (PyPI may be temporarily unavailable)
